# Emby-JS-Glow

> **一套通过AI生成的 Emby Web 前端美化脚本套件。**  
> 通过 CustomCssJS 插件注入，一个模块一个文件，按需安装、随时卸载。

`可增量安装的 Emby 前端增强`　·　`不修改 Emby 本体`　·　`不依赖服务端改造`

---

## 这是什么

Emby 的原生 Web 界面能用，但"看起来就是 Emby"。

Emby-JS-Glow通过**CustomCssJS 插件将JavaScript代码注入页面中**，把首页、详情页、播放器等位置**重做视觉与交互**，同时尽量保持原生行为（滚动、路由、播放仍由 Emby 自己负责）。

每个模块都是**独立单文件**：

- 想用就粘贴一份，不用就删掉；
- 模块之间互不依赖，可以只装其中一个；
- 卸载 = 清空对应内容 + 刷新，不留痕迹。

## 运行前提（所有模块通用）

Emby-JS-Glow 的模块**不是 Emby 插件**，必须通过 **CustomCssJS** 插件注入：

1. Emby 后台 → **插件 → 目录**；
2. 搜索 **Custom CSS and JS** → 安装 → 重启 Emby；
3. 重启后，后台 → 设置 → 侧栏出现 **自定义 CSS/JS（CustomCssJS）**，才算装好。

> 没有这个插件，页面上没有任何位置可以粘贴脚本。

## 通用安装步骤

对任何模块都一样：

1. 确认已装 **CustomCssJS** 插件（见上）；
2. Emby 后台 → **设置 → 自定义 CSS/JS**；
3. 打开对应模块的 `.js` 文件，**全选复制**，整份粘贴（覆盖旧内容）；
4. 保存 → 回首页 **Ctrl+F5** 强制刷新；
5. 控制台看到该模块的日志与构建标签，即为成功。

## 设计原则

这些原则决定了每个模块"长什么样、怎么工作"：

| 原则          | 含义                                      |
| ----------- | --------------------------------------- |
| **不侵入原生**   | 滚动、路由、播放、顶栏都交给 Emby 自己；模块只负责"画得好看、点得顺手" |
| **单文件交付**   | 依赖（如 Swiper 库、样式）全部内联，不额外拉取网络资源         |
| **可干净卸载**   | 移除内容 + 刷新即恢复原生，不在服务端留任何痕迹               |
| **克制**      | 不加多余按钮、不做炫技动画；动效只服务于"看清内容"              |
| **一次只改一件事** | 每个模块职责单一，出问题容易定位、回滚只影响一个位置              |

## 适配范围

- **Emby Server**：4.7 / 4.11（4.11.0.9 实测）
- **客户端**：网页端（Chrome/Edge 内核）、**Emby Theater**（Electron 18 / Chromium 100）
- 已知约束：模块只使用 Chromium 100 支持的特性（无 `:has()`、无 `mask-composite` 等）

## 版本与兼容

- 每个模块**独立版本**（如 `HomeSwiper v1.0`），套件本身不单独发版本；
- 每次构建会写入**构建标签**（如 `b20261025140557`），用于在控制台确认客户端跑的是哪一版；
- 模块之间不共享运行时，升级其中一个不影响其它。

## 已知限制（套件层面）

- 依赖 CustomCssJS 插件，插件本身失效时所有模块一起失效；
- 脚本以单文件形式下发，**不享受静态资源强缓存**，每次进首页都会重新下载整段；
