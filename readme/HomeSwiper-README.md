# 模块 ①：首页轮播（HomeSwiper）

> 属于 **Emby-JS-Glow** 套件　·　当前版本 **v1.1**　·　[返回套件说明](../README.md)

**把 Emby 首页顶部变成"带预告片的电影轮播"。** 一个文件、粘贴即用。

> ⚠️ **运行前提：Emby 必须装有 CustomCssJS 插件**（自定义 CSS/JS）。本脚本不是 Emby 插件，而是通过该插件注入的脚本。

`v1.1`　·　Emby 4.7 / 4.11　·　单文件部署

---

## 特点

|             |                                                           |
| ----------- | --------------------------------------------------------- |
| **单文件**     | 全部内联（Swiper 库 + 样式 + 逻辑），粘贴进 Emby 的 CustomCssJS 即可，无需改服务端 |
| **四种挑选方式**  | 随机换批 / 最近入库 / 评分最高 / 最近观看，面板里随时切换                       |
| **自动播预告片**  | 读取条目 `trailers` 目录下的本地预告片，有声优先；被拦截会 300ms 后重试一次，仍失败则降级静音，等你第一次操作补声 |
| **进度条**     | 图片阶段显示"还有多久翻页"，预告片阶段显示播放进度                                |
| **静音按钮**    | 预告片右下角，鼠标移到轮播区才出现，两态图标                                    |
| **长简介自动滚动** | 放不下时缓慢循环上滚（提词器式），放得下就不动                                   |
| **两态布局不跳**  | 图片→视频切换时，标题/评分/标语/按钮位置一个像素都不动                             |
| **不破坏原生**   | 轮播只是首页内容里的第一块，下面的分区、滚动、顶栏都保持 Emby 原生行为                    |

## 前置依赖（必须）

本脚本**不是** Emby 插件，必须通过 **CustomCssJS** 插件注入才能运行。

1. Emby 后台 → **插件 → 目录**；
2. 搜索 **Custom CSS and JS**（作者 `InfiniteSky` 的版本即可）；
3. 安装 → 重启 Emby；
4. 重启后，后台 → 设置 → 侧栏出现 **自定义 CSS/JS（CustomCssJS）** 这一项，才算装好。

> 没装这个插件，页面上没有任何地方能粘贴 `HomeSwiper.js`，脚本也没有执行入口。

## 环境要求

- **Emby Server** 4.7 / 4.11（已实测 4.11.0.9）
- 客户端：网页端（Chrome/Edge 内核）与 **Emby Theater**（Electron 18 / Chromium 100）均已适配
- 条目需要有 **Backdrop（背景图）** 才会进轮播；预告片来自 `trailers` 子目录（可选）

## 安装

1. 确认已装 **CustomCssJS** 插件（见上「前置依赖」）；
2. Emby 后台 → **设置 → 自定义 CSS/JS（CustomCssJS）**；
3. 打开仓库根目录的 [`HomeSwiper.js`](../HomeSwiper.js)，**全选复制**，整份粘贴进去（覆盖旧内容）；
4. 保存；
5. 回首页 **Ctrl+F5** 强制刷新。

打开浏览器控制台，看到这一行就说明装好了：

```
[HomeSwiper] b20261026081738
```

> 当前模块的日志前缀仍是 `[HomeSwiper]`（代码里的历史名），下一版会统一成 `[Glow]`。  
> **判断是否装好，看构建标签 `b20261026081738` 即可。**

## 设置

点顶栏右侧的轮播图标（或设置页里的入口）打开面板：

| 项             | 说明                                        | 默认     |
| ------------- | ----------------------------------------- | ------ |
| 媒体库           | 从哪个库抽条目                                   | 第一个可见库 |
| 挑选方式          | 随机换批 / 最近入库 / 评分最高 / 最近观看                 | 随机换批   |
| 轮播数量          | 每轮抽多少条；选「随机换批」时 = 每次向服务器请求的条数             | 20     |
| 每张停留（秒）       | 图片阶段停留时长                                  | 10     |
| 播放预告片         | 关闭后全程图片轮播                                 | 开      |
| 预告片音量（0–1）    | 预告片播放音量                                   | 0.6    |

> **改任何设置保存后立即生效**（不刷新）。代价是轮播会整块重建、并回到第一条。

### 挑选方式说明

| 方式 | 行为 |
| --- | --- |
| **随机换批**（默认） | 每次向服务器要一批（条数 = 轮播数量），翻到最后一张自动再取一批，不会看腻同一批 |
| **最近入库** | 按入库时间倒序，播完一轮回到开头 |
| **评分最高** | 按评分倒序，播完一轮回到开头 |
| **最近观看** | 按你最近播放的时间倒序，播完一轮回到开头 |

> 排序被服务器拒绝时（个别库不支持该排序），会**回落「最近入库」**并在控制台 `[HomeSwiper]` 日志里说明原因。

## 常见问题

**Q：后台找不到「自定义 CSS/JS」这一项？**  
说明 **CustomCssJS 插件没装或没重启**。先按上面「前置依赖」装好并重启 Emby。

**Q：装好了但首页没变化？**  
先看控制台有没有 `[HomeSwiper]` 前缀的日志（这是当前模块的历史前缀）；没有说明脚本没执行（检查是否粘贴完整、是否被浏览器扩展拦了）。

**Q：右侧不播预告片？**  
三种可能：① 该条目没有本地预告片（`trailers` 目录）；② 设置里关了"播放预告片"；③ 轮播太窄或面板太矮（窗口宽度不足 680px 时不播）。控制台的 `[HomeSwiper:trailer]` 日志会逐条说明原因。

**Q：没有声音？**  
浏览器不允许"无用户交互时的自动播放带声音"。脚本先尝试有声播放，被拒后 **300ms 重试一次**；仍被拒就降级静音，并提示「点击任意区域开启声音」，等你第一次点击/按键时补上声音。也可以直接点右下角静音按钮。

**Q：改完设置感觉卡了一下？**  
这是整块重建（设计如此）。

**Q：怎么彻底卸载？**  
清空 CustomCssJS 里的内容，保存并强制刷新。脚本不会在服务端留下任何东西。

## 版本

### v1.1（当前版本 · 构建 `b20261026081738`）

- **四种挑选方式**：随机换批 / 最近入库 / 评分最高 / 最近观看，面板里随时切换，选完保存立即生效
- **默认方式改为「随机换批」**：每次向服务器请求一批（条数 = 轮播数量），翻到末尾自动换下一批
- 「最近入库 / 评分最高 / 最近观看」播完一轮后回到开头，不会停住
- 预告片有声播放被拒后 **300ms 重试一次**，仍失败才降级静音 + 等手势补声
- 库不支持所选排序时**回落「最近入库」**，控制台记录原因，不再整段失败

### v1.0（首个公开版本 · 套件第 1 个模块）

- 首页整屏轮播：剧照背景 + 可读信息层 + 播放/详情

- 进度条（图片倒计时 / 预告片进度）、静音按钮、长简介自动滚动
- 顶部媒体库条、设置面板（改完即时生效）
- 兼容网页端与 Emby Theater
- **依赖 CustomCssJS 插件**（非 Emby 插件本身）
